# Cratebox keyboard + trackpad

F12 in the app shows this list. Deck keys follow the controller's sides: the left hand plays the left deck
(1, or 3 after a layer switch in 4-deck mode), the right hand the right deck (2, or 4).

| Left deck | Right deck | Does |
|---|---|---|
| X | , | Play / pause |
| Z | M | CUE (hold to preview) |
| A | J | SYNC |
| S | K | 4-beat loop on / off |
| D | L | Loop ½ |
| F | ; | Loop ×2 |
| C | . | Beat jump back 4 |
| V | / | Beat jump on 4 |
| 1 2 3 4 / Q W E R | 7 8 9 0 / U I O P | Pads 1-8 in the current pad mode (PAD FX: held; Shift: delete hot cue) |
| ` | \ | Layer: left side 1 ⇄ 3, right side 2 ⇄ 4 (4 DECKS) |

| Key | Does |
|---|---|
| B | Beat FX on / off |
| [ ] | Previous / next effect |
| - = | Fewer / more beats |
| ↑ ↓ | Move through the tracks |
| Enter | Load onto the first free deck |
| Shift ← / → | Load onto the left / right deck |
| Ctrl F | Search |
| Ctrl A | Select all tracks |
| Delete | Remove from this playlist |
| F1 | WAVE (just the waveforms) |
| F2 | 4 DECKS |
| F3 | BROWSE (big library) |
| F4 | HEAT panel |
| Ctrl R | REC on / off |
| ↑ ↓ | WAVE mode: pops up the library; then 1 2 3 4 load on that deck |
| F11 | Full screen on/off |
| F12 | Shortcut list |
| Esc | Close panels, stop MIDI learn |

Trackpad: knobs drag up/down (Shift = fine); faders grab and slide (they don't jump to the click); two-finger
scroll nudges knobs and faders, zooms a waveform, and sideways scrubs a paused one; double-click puts a knob,
the tempo or the crossfader back in the middle. Drag the library's top edge or the line beside the playlists
to resize them (double-click: back to automatic).
